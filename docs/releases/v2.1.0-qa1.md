# QA Build

The v2.1 audio, rendering, and Android compatibility work in the separate QA app.
This candidate uses the same native libraries as the main v2.1 APK.

Thanks to Andrew Nakas and contributors for the fixes and AlanConstantino for
the integration and RP6 testing. [Full release notes](https://github.com/Buku313/Skate3-Mobile/releases/tag/v2.1.0).

Install **Skate3-Mobile-QA.apk** over your existing QA app without uninstalling.
It does not replace the main app. Older QA builds need this one manual update
to switch to their own update channel. No retail game files are included.

## Português

Versão QA com as correções de áudio, renderização e compatibilidade da v2.1.
Usa as mesmas bibliotecas nativas do APK principal.

Instale **Skate3-Mobile-QA.apk** por cima do aplicativo QA atual, sem desinstalar.
Não substitui o aplicativo principal. Esta atualização manual é necessária uma
vez para que o QA antigo passe a receber suas próprias atualizações.
Nenhum arquivo comercial do jogo está incluído.
