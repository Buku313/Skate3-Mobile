# Skate 3 Mobile v2.1.0 DEV

New audio, rendering, and Android startup fixes are here. Huge thanks to
[Andrew Nakas](https://github.com/andrewnakas) and contributors for the underlying
work, and [AlanConstantino](https://github.com/AlanConstantino) for integrating
it and testing on Retroid Pocket 6 in [PR #123](https://github.com/Buku313/Skate3-Mobile/pull/123).
Alex McHugh's Skate3Recomp and ReXGlue/Xenia remain the foundation of this port.

## Download

Most players want **Skate3-Mobile-Android.apk**. Install over your existing
main app. Do not uninstall first. Android will ask you to approve the update.
Your extracted game files stay in place.

[Download the main APK](https://github.com/Buku313/Skate3-Mobile/releases/download/v2.1.0/Skate3-Mobile-Android.apk)
or [get the separate QA Build](https://github.com/Buku313/Skate3-Mobile/releases/download/v2.1.0-qa1/Skate3-Mobile-QA.apk).
The debug APK is for users of the separate developer app.

Older QA and developer builds used the main app's update address. Install the
matching v2.1 APK once, without uninstalling. From this version onward, each
app receives updates for its own package only.

## What changed

- Audio decoding, stereo playback, rendering, and startup improvements from PR #123.
- Safer handling of unknown game calls and unfinished GPU cleanup. These stop
  a failed session instead of allowing unsafe operations to continue.
- Package, version, checksum, and signing-key checks for app updates.

Original Skater is still the default. Seiyu and the Mod Store are included.
System Driver is recommended. Custom drivers remain optional.

The hardened build reached native gameplay and passed a short Home/resume test
on RG406V. Eight host test suites, APK signing checks, and native-library
alignment checks passed. Alan's RP6 gameplay report applies to his original
AV3 contribution build; this exact release still needs reports on other devices.
See the [test record](https://github.com/Buku313/Skate3-Mobile/blob/main/docs/V2_1_RELEASE_CHECKS.md)
for scope and remaining limitations. Bugs are still possible.

No retail game files are included. Android 13+, ARM64, Vulkan, and your own
supported Xbox 360 game dump are required.
